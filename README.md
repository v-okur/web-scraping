
# Football Scraper

This project is an educational web scraping application developed using Node.js, Puppeteer, and MongoDB. The project involves scraping football player data from the Transfermarkt website and storing it in appropriate collections within a MongoDB database.

## Purpose

The primary goal of this project is to provide hands-on experience in web scraping and database integration. It aims to enhance knowledge and skills in the following areas:

* Web scraping techniques and [**Puppeteer**](https://pptr.dev/) usage
* Extracting data from dynamic web pages
* Storing and querying data in **MongoDB**
* Developing applications with **Node.js**

## Technologies Used

* **Node.js:** The primary development platform for the application.
* **Puppeteer:** A headless browser automation library used to scrape data from the Transfermarkt website.
* **MongoDB:** A NoSQL database used to store the scraped data.

## Features

* **Data Collection:** Fetches information such as player names, ages, positions, and market values from the Transfermarkt website.
* **Dynamic Page Handling:** Uses Puppeteer to extract data from JavaScript-rendered dynamic pages.
* **Database Integration:** Stores the collected data into MongoDB collections.
* **Data Analysis:** Enables querying and analyzing the scraped data.
